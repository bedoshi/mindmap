# 機能仕様

MindMeister 風のマインドマップアプリケーションの機能仕様。実装の詳細（構成・技術的な決定）は `.claude/skills/mindmap-app-architecture/SKILL.md`、方針決定の経緯は [decisions.md](./decisions.md) を参照。

## 提供形態

| 形態 | 動作環境 | マップの保存先 |
| --- | --- | --- |
| Web 版 | ブラウザ | ブラウザの localStorage |
| Electron 版（デスクトップアプリ） | Windows / macOS / Linux | OS のユーザーデータディレクトリ内の XML ファイル |

- 両者は同じ UI・同じコードで、保存先だけが異なる。
- バックエンド（サーバー）は持たない。

## マップの管理

- 複数のマップを作成・切り替え・削除できる。ツールバーの「☰ マップ」で一覧パネルを開く。
- 一覧は更新日時の新しい順に並び、起動時には最後に更新したマップが開く。マップが 1 つもなければ空のマップを自動で作成する。
- マップのタイトルはルートノード（中心トピック）のテキスト。タイトルを変えたいときはルートノードを編集する。
- マップを削除すると元に戻せない（確認ダイアログあり）。開いているマップを削除した場合は、残っている最新のマップが開く。残りが無ければ新しい空のマップを作成する。
- 一覧パネルの下部に現在の保存先（Electron 版はディレクトリの絶対パス）を表示する。
- マップを切り替えると、Undo/Redo の履歴・選択・表示位置はリセットされ、一覧パネルは閉じる。

## マップの構造

- 1 つのマップは 1 つのルート（中心トピック）と、その子孫ノードからなるツリー構造。
- ルートは削除・移動できない。
- ルート直下のノードはルートの左右に自動で振り分けられ、ノード数（部分木の大きさ）が少ない側に新しいノードが追加される。
- ルート直下の枝ごとに色が割り当てられ、その枝に属する子孫ノードと接続線は同じ色で描画される。
- ノードのテキストは 1 行。

## レイアウト

- ノードの位置は常に自動計算される（手動配置はしない）。
- ルートを中心に、各部分木を縦に積み上げて左右に広げる。
- ノードの幅はテキスト長に応じて自動で決まる。

## ノードの編集

| 操作 | マウス | キーボード |
| --- | --- | --- |
| 選択 | クリック | 矢印キーで隣のノードへ移動 |
| 子ノードを追加 | ツールバー「＋ 子」 | `Tab` |
| 兄弟ノードを追加 | ツールバー「＋ 兄弟」 | `Enter`（ルート選択時は子を追加） |
| テキストを編集 | ダブルクリック | `F2` / `Space` / 任意の文字キー（その文字から入力開始） |
| 編集の確定 | 他の場所をクリック | `Enter` |
| 編集を確定して子を追加 | – | 編集中に `Tab` |
| 編集のキャンセル | – | `Esc` |
| 削除（子孫ごと） | ツールバー「削除」 | `Delete` / `Backspace` |
| 折りたたみ / 展開 | ノード外側の丸ボタン | – |
| 別の親へ付け替え | ノードを別のノードへドラッグ＆ドロップ | – |
| 選択解除 | 背景をクリック | `Esc` |
| 元に戻す / やり直す | ツールバー | `Ctrl+Z` / `Ctrl+Shift+Z`・`Ctrl+Y` |

- 新しく追加したノードは即座に編集状態になる。
- テキストが空のまま確定・キャンセルされた末端ノードは自動的に削除される。
- 折りたたんだノードには、隠れている子孫の数がボタンに表示される。
- 付け替え先として自分自身・自分の子孫・現在の親は選べない。
- IME で変換中に押した `Enter` は確定操作として扱わない（変換の確定のみ）。
- Undo/Redo の履歴はマップごとに最大 100 件。

## 表示

| 操作 | 方法 |
| --- | --- |
| スクロール（パン） | 背景をドラッグ / マウスホイール（トラックパッドの 2 本指スクロール） |
| ズーム | `Ctrl`+ホイール（ピンチ）/ ツールバーの「−」「＋」/ `Ctrl`+`-`・`Ctrl`+`=` |
| 全体を表示 | ツールバー「全体」/ `Ctrl`+`0` |

- ズーム倍率は 20%〜300% の範囲。
- OS のダークモード設定に追従する。
- Electron 版では、アプリのズームショートカットと衝突しないよう、Electron 標準のページズーム（`Ctrl+=` など）はメニューから外している。

## 保存

- 変更は自動保存される（最後の変更から約 0.6 秒後に書き込む）。
- `Ctrl+S` またはツールバーの「保存」で、待たずにその場で保存できる。
- ツールバーに保存状態を表示する: 保存済み / 未保存 / 保存中… / 保存失敗。
- ウィンドウ（タブ）を閉じるとき・リロードするときにも保留中の変更を書き出す。
- 保存に失敗した変更は捨てずに保持し、次の保存時に再試行する。失敗時はメッセージを表示する。
- マップの切り替え・作成・削除・読み込みの前には、必ず保留中の変更を書き出す。

### 保存先

| 環境 | 保存先 |
| --- | --- |
| Web 版 | ブラウザの localStorage（キー `mindmap.map.<マップID>`、値は XML 文字列とタイトル・更新日時を含む JSON） |
| Electron 版 / Windows | `%LOCALAPPDATA%\mindmap\maps\<マップID>.xml`（通常 `C:\Users\<ユーザー名>\AppData\Local\mindmap\maps`） |
| Electron 版 / macOS | `~/Library/Application Support/mindmap/maps/<マップID>.xml` |
| Electron 版 / Linux | `$XDG_DATA_HOME/mindmap/maps/<マップID>.xml`（未設定なら `~/.local/share/mindmap/maps`） |

- マップ ID は UUID。ファイル名に使える文字は英数字・`_`・`-` に限定する。
- Electron 版では環境変数 `MINDMAP_DATA_DIR` を設定すると、そのディレクトリを保存先として使う（検証用）。
- Electron 版の書き込みは一時ファイルに書いてから置き換えるため、書き込み途中で異常終了しても元のファイルは壊れない。

## 書き出し / 読み込み

- 「書き出し」で開いているマップを XML ファイルとしてダウンロード（保存）できる。ファイル名は `<マップのタイトル>.xml`。
- 「読み込み」で XML ファイルを**新しいマップとして**取り込み、そのマップを開く。既存のマップは上書きされない。
- Web 版と Electron 版で同じ XML 形式を使うため、ファイル経由で相互に受け渡せる。
- 形式が不正なファイルはエラーメッセージを表示して取り込まない。

## XML 形式

```xml
<?xml version="1.0" encoding="UTF-8"?>
<mindmap version="1">
  <node id="<ルートノードのID>" text="中心トピック">
    <node id="…" text="子ノード" side="right" collapsed="true">
      <node id="…" text="孫ノード"/>
    </node>
    <node id="…" text="左側の子ノード" side="left"/>
  </node>
</mindmap>
```

| 要素 / 属性 | 意味 |
| --- | --- |
| `mindmap@version` | 形式のバージョン（現在 `1`） |
| `node` | ノード。入れ子で親子関係を表し、子要素の順序が兄弟の表示順。`mindmap` 直下の最初の `node` がルート |
| `node@id` | ノードID。無い・重複している場合は読み込み時に振り直す |
| `node@text` | 表示テキスト。改行などは文字参照（`&#10;` 等）でエスケープする |
| `node@side` | ルート直下のノードのみ有効。`left` または `right`。省略時は `right` |
| `node@collapsed` | `true` のとき折りたたみ状態。省略時は展開 |

- ルート以外のノードに付いた `side` は無視する。
- 不明な要素・属性は無視する（将来の拡張用）。
